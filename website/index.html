Standalone launcher page?

Not possible, and we checked: Infinite Craft refuses to be embedded in other sites (a frame-ancestors policy) and browsers do not let one site control another, so a launcher page cannot drive the real game. The console snippet and the bookmarklet are the only extension-free ways in.

School or work computers

Nothing here needs admin rights or installs anything, but managed devices may still block it. Honest list of what can go wrong:

  • Developer Tools disabled by policy - the console won't open. Bookmarklets may still work.
  • Pasting into the console / javascript: URLs blocked by policy or a content filter.
  • The network blocks the script host or the multiplayer server - the snippet shows an alert.
  • Infinite Craft itself may be blocked (it is a game).

We don't provide ways around such restrictions; if your network blocks it, it is blocked.

How a game goes

  1. Create / join a room with a 5-letter code (max 4 players, 2 to start). The host picks the mode and timer (1-30 min or unlimited).
  2. Everyone submits one element they want the group to craft. Nothing is shown until all are in.
  3. Vote. One final, hidden vote each; no voting for yourself; ties are broken randomly by the server.
  4. Play. Everyone starts at the same server-timed GO. The server verifies the winning craft and keeps the clock.

Use an empty save slot for each round (the game has 3). Multiplayer never deletes or edits your saves; it warns you if a slot contains elements that aren't part of the round.
